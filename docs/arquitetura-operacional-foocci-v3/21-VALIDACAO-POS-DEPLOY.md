# Validação pós-deploy

Depois de um deployment Railway `SUCCESS`:

1. abrir `/comercial/whatsapp`;
2. confirmar os novos textos de 01 e 02;
3. confirmar que `NONE` não aparece sob o template 03;
4. clicar `Atualizar status`;
5. somente então submeter os modelos ainda não submetidos;
6. registrar os estados devolvidos pela Meta.
