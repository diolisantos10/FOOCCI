# 16 — Liderança, Coaching e Gestão Comercial

## Princípio

Gestor não é o melhor vendedor promovido. É responsável por criar **sistema no qual o time melhora**.

# 1. Responsabilidades

- meta;
- estratégia;
- capacidade;
- contratação;
- onboarding;
- coaching;
- pipeline;
- forecast;
- qualidade;
- processo;
- cultura;
- integração com marketing/CS/produto.

# 2. 1:1

Agenda:
- pessoa;
- resultados;
- bloqueios;
- habilidade;
- plano;
- compromisso.

Não transformar 1:1 em atualização de pipeline.

# 3. Coaching

Modelo GROW:
- Goal;
- Reality;
- Options;
- Way forward.

Gestor pergunta antes de dar resposta.

# 4. Call review

Avaliar:
- preparação;
- abertura;
- discovery;
- profundidade;
- valor;
- demo;
- objeção;
- próximo passo.

Feedback precisa apontar **comportamento observável**.

Ruim: “seja mais consultivo.”

Bom: “aos 6 minutos ele mencionou churn e você apresentou CRM sem perguntar frequência, impacto ou causa.”

# 5. Skill matrix

Mapear por vendedor:
- produto;
- prospecção;
- discovery;
- demo;
- valor;
- objeção;
- negociação;
- CRM;
- forecast;
- comunicação.

Treinamento deve atacar gap real.

# 6. Ramp

Novo vendedor passa por:
- conhecimento;
- observação;
- role play;
- sombra;
- supervisão;
- autonomia.

Não liberar porque “assistiu tudo”.

# 7. Reunião de forecast

Não perguntar “vai fechar?”

Perguntar:
- qual evidência;
- quem decide;
- o que falta;
- data;
- risco;
- concorrência;
- próximo passo.

# 8. Performance

Separar:
- skill;
- effort;
- territory/list;
- process;
- product/market.

Nem todo underperformance é falta de esforço.

# 9. PIP/desenvolvimento

Plano deve conter:
- gap;
- evidência;
- comportamento esperado;
- suporte;
- prazo;
- métrica.

# 10. Cultura

Valores comerciais:
- verdade;
- disciplina;
- curiosidade;
- responsabilidade;
- respeito;
- melhoria contínua.

# 11. Incentivo

Plano de comissão não deve premiar:
- venda sem fit;
- desconto excessivo;
- receita que cancela rapidamente;
- pipeline inflado.

# 12. Contratação

Avaliar:
- raciocínio;
- comunicação;
- coachability;
- disciplina;
- ética;
- resiliência;
- aprendizado.

Experiência no setor ajuda, mas não substitui capacidade de aprender.

# 13. Exercício

Gestor recebe vendedor com:
- atividade alta;
- muita reunião;
- baixa conversão;
- discovery raso.

Criar plano de coaching de 30 dias com comportamento, prática e métrica.
