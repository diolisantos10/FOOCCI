# 09 — CRM, Pipeline e Forecast

## Princípio

CRM não é arquivo morto. É o sistema operacional da equipe comercial.

# 1. Higiene de CRM

Todo registro ativo precisa ter:
- empresa;
- contato;
- cargo;
- origem;
- estágio;
- dor;
- valor potencial;
- próxima ação;
- data;
- dono;
- última interação.

Se não há próximo passo, a oportunidade está parada.

# 2. Pipeline

Estágios devem representar **evidência de avanço**, não sensação.

Exemplo:
1. Lead identificado
2. Contato realizado
3. Conversa iniciada
4. Qualificado
5. Discovery concluído
6. Demo/proposta
7. Decisão
8. Fechado ganho/perdido

# 3. Entry/exit criteria

Exemplo:

**Qualificado → Discovery**
Só entra se:
- existe problema;
- fit mínimo;
- pessoa correta;
- próxima reunião.

**Discovery → Demo**
Só entra se:
- dor priorizada;
- impacto;
- decisores conhecidos;
- agenda para prova.

# 4. Pipeline velocity

Conceito:

**velocidade ≈ oportunidades × ticket médio × taxa de ganho ÷ ciclo de vendas**

Serve para entender onde crescer:
- mais oportunidades;
- maior ticket;
- maior conversão;
- ciclo menor.

# 5. Aging

Medir dias por estágio.

Oportunidade velha sem ação deve ser:
- reativada;
- requalificada;
- movida para nurture;
- perdida.

Não deixar “zumbi” melhorar forecast artificialmente.

# 6. Forecast

Categorias recomendadas:
- **Pipeline:** existe oportunidade.
- **Best case:** pode fechar no período, ainda depende de pontos importantes.
- **Commit:** evidências fortes de fechamento no período.
- **Closed:** concluído.

Commit não é “eu acho”.

# 7. Evidências para commit

- decisor envolvido;
- dor validada;
- solução aceita;
- comercial conhecido;
- processo decisório claro;
- próximo passo agendado;
- prazo coerente.

# 8. Forecast matemático

Forecast ponderado pode ajudar:
**valor × probabilidade histórica do estágio**.

Mas não substituir inspeção qualitativa.

# 9. Métricas

## Topo
- leads;
- contatos válidos;
- respostas;
- reuniões.

## Meio
- qualificação;
- show rate;
- demo;
- proposta.

## Fundo
- win rate;
- ticket;
- ciclo;
- receita.

## Saúde
- aging;
- cobertura de pipeline;
- no-decision;
- perda por motivo;
- follow-up vencido.

# 10. Cobertura

Se meta é R$ 100 mil e win rate real é 25%, pipeline bruto necessário será maior que R$ 100 mil.

Não usar multiplicador fixo universal; usar histórico.

# 11. Revisão semanal

Perguntas:
- o que entrou;
- o que avançou;
- o que travou;
- o que sai;
- próximos passos;
- riscos;
- ajuda necessária.

# 12. Exercício

Receber pipeline fictício com 20 oportunidades e:
- corrigir estágio;
- remover zumbis;
- definir forecast;
- listar riscos;
- propor ações.
