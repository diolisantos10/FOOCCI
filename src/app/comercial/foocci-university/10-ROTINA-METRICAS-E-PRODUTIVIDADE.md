# 10 — Rotina Comercial, Métricas e Produtividade

## Princípio

Alta performance é sistema de hábitos + feedback + dados. Não é trabalhar até exaustão.

# 1. Rotina de SDR

Diário:
- priorizar lista;
- prospectar;
- responder retornos;
- atualizar CRM;
- preparar reuniões;
- analisar motivos de resposta/não resposta.

Semanal:
- revisar mensagens;
- fontes;
- qualidade;
- conversão por ICP;
- contatos que devem sair da cadência.

# 2. Rotina de Closer/AE

Diário:
- reuniões;
- preparação;
- follow-ups;
- negociação;
- atualização de riscos.

Semanal:
- pipeline;
- forecast;
- contas prioritárias;
- oportunidades travadas;
- win/loss.

# 3. Time blocking

Separar blocos:
- prospecção;
- reunião;
- follow-up;
- análise;
- administração.

Context switching destrói qualidade.

# 4. Métrica de atividade x resultado

Atividade:
- ligações;
- mensagens;
- reuniões.

Resultado:
- respostas positivas;
- oportunidades;
- receita.

Qualidade:
- fit;
- show rate;
- win rate;
- churn inicial;
- motivo de perda.

Nunca otimizar só volume.

# 5. Conversões

Exemplo de funil:
100 contatos → 20 respostas → 8 reuniões → 5 oportunidades → 2 vendas.

Problema pode estar em qualquer transição.

# 6. Diagnóstico por gargalo

Se pouca resposta:
lista/mensagem/canal.

Se resposta, pouca reunião:
CTA/qualificação.

Se reunião, pouca oportunidade:
ICP/discovery.

Se oportunidade, pouca venda:
valor/demo/decisão/objeção.

Se vende e cancela:
qualificação/promessa/onboarding.

# 7. Leading e lagging indicators

Leading:
- contatos qualificados;
- reuniões;
- próximos passos;
- pipeline criado.

Lagging:
- receita;
- win rate;
- churn.

Gerenciar só lagging é olhar retrovisor.

# 8. Meta

Meta deve descer:
receita → vendas → oportunidades → reuniões → atividade.

Usar taxas históricas e atualizar.

# 9. Capacidade

Não aumentar prospecção se o time não consegue responder os interessados.

Capacidade de atendimento é parte do desenho de aquisição.

# 10. Diário de melhoria

Cada vendedor mantém:
- objeção difícil;
- erro;
- frase que funcionou;
- insight;
- pergunta nova;
- aprendizado de produto.

Transformar experiência em ativo coletivo.
