# Trilhas por função

## SDR
Produto → ICP → Prospecção → Discovery básico → CRM → Escrita → Ética → Certificação.

## Closer/AE
Produto → Discovery → Value Selling → Demo → Objeções → Negociação → Pipeline → Certificação.

## Account Manager/CS Comercial
Produto → Handoff → Adoção → Expansão → Business Review → Risco.

## Líder
Todas as bases + Forecast → Coaching → Hiring/Ramp → RevOps → Incentivos.

## Agente de IA
Produto → regras → ferramentas → casos → shadow → adversarial → certificação.

# Matriz de competências

Cada competência é avaliada em 4 níveis:

**0 — desconhece**
**1 — explica**
**2 — aplica**
**3 — adapta/ensina**

# Resultado esperado

A University não forma “tirador de pedido”. Forma profissional capaz de:
- pensar;
- diagnosticar;
- comunicar;
- provar;
- negociar;
- operar;
- aprender;
- ensinar;
- usar IA com responsabilidade.
