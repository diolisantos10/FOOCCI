# 17 — RevOps e Operação Comercial

## Objetivo

Ensinar como receita vira um sistema integrado de Marketing → Vendas → Implantação/CS → Expansão.

# 1. Definição

Revenue Operations conecta:
- processo;
- dados;
- tecnologia;
- pessoas;
- governança.

Objetivo: reduzir atrito e aumentar previsibilidade.

# 2. SLA Marketing → Comercial

Definir:
- o que é lead;
- o que é MQL/SQL se esses termos forem usados;
- prazo de atendimento;
- campos obrigatórios;
- devolução;
- feedback.

# 3. Roteamento

Leads podem ser distribuídos por:
- região;
- segmento;
- porte;
- origem;
- round-robin;
- especialidade;
- capacidade.

Regra precisa ser auditável.

# 4. Deduplicação

Uma empresa/pessoa não deve virar múltiplas oportunidades sem motivo.

# 5. Fonte

Registrar:
- origem;
- campanha;
- canal;
- parceiro;
- lista.

Sem isso, CAC e eficiência ficam cegos.

# 6. Definições

Criar dicionário:
- lead;
- contato;
- conta;
- oportunidade;
- receita;
- churn;
- expansão.

Métrica sem definição compartilhada gera reunião sobre planilha.

# 7. Governança de campos

Campo deve existir porque:
- roteia;
- segmenta;
- prevê;
- automatiza;
- mede.

Evitar CRM com 100 campos que ninguém usa.

# 8. Automação

Automatizar:
- tarefa repetitiva;
- roteamento;
- lembrete;
- enriquecimento;
- alerta;
- sincronização.

Não automatizar processo ruim sem primeiro corrigir lógica.

# 9. Attribution

Diferenciar:
- first touch;
- last touch;
- multi-touch.

Não prometer causalidade perfeita.

# 10. Funnel analytics

Analisar:
- volume;
- conversão;
- tempo;
- valor;
- cohort;
- origem;
- ICP;
- vendedor.

# 11. Data quality

Rotina:
- campos vazios;
- duplicados;
- estágio errado;
- data vencida;
- owner;
- motivo de perda.

# 12. Capacity planning

Meta precisa caber em:
- quantidade de SDRs;
- reuniões;
- closers;
- capacidade de implantação;
- suporte.

Receita vendida além da capacidade operacional gera churn.

# 13. Experimentação

Experimento comercial deve ter:
- hipótese;
- grupo;
- mudança;
- métrica;
- janela;
- decisão.

Exemplo:
“Abordagem baseada em dependência de marketplace aumenta resposta positiva em ICP A?”

# 14. Dashboard

Níveis:
- executivo;
- gestor;
- vendedor;
- canal.

Cada um vê o que pode agir.

# 15. Auditoria

Toda alteração estrutural relevante deve responder:
- quem mudou;
- quando;
- por quê;
- efeito.

# 16. Exercício

Desenhar o fluxo completo de um lead:
origem → roteamento → SDR → oportunidade → venda → onboarding → receita → expansão.
