# 2. Processo seletivo

- currículo;

# 4. Onboarding

Semana/etapas conceituais:
- empresa;
- cliente;
- produto;
- mercado;
- processo;
- ferramentas;
- sombra;
- role play;
- certificação.

# 5. Ramp

Ramp é aumento progressivo de:
- conhecimento;
- atividade;
- dificuldade;
- autonomia;
- meta.

# 6. Buddy/shadow

Novo vendedor observa:
- chamadas boas;
- chamadas ruins;
- CRM;
- demo.

# 7. Teach-back

Aluno ensina de volta.

Se não consegue explicar, não domina.

# 8. Certificação

Antes de autonomia:
- produto;
- discovery;
- demo;
- objeções;
- CRM;
- ética.

# 9. Meta de ramp

Não aplicar meta cheia no dia 1 sem pipeline/território.

# 10. Falha de onboarding

Sinais:
- sabe feature, não sabe dor;
- usa script sem ouvir;
- CRM ruim;
- promete demais.

# 11. Offboarding

Preservar:
- contas;
- notas;
- contexto;
- histórico.

# 12. Exercício

Desenhar plano de ramp de 30/60/90 dias para novo closer Foocci.
