# 19 — Ética, Compliance e Precisão Comercial

## Regra central

Venda forte não precisa de mentira.

# 1. Proibido

- inventar cliente;
- inventar case;
- inventar métrica;
- inventar integração;
- esconder limitação material;
- garantir ROI;
- criar urgência falsa;
- falsificar escassez;
- fingir relação pessoal;
- burlar opt-out;
- usar dado sem autorização;
- atacar concorrente com afirmação sem fonte.

# 2. Precisão

Classificar afirmação:
- fato;
- cenário;
- estimativa;
- hipótese;
- opinião.

# 3. Números

Sempre declarar:
- fonte;
- período;
- premissa;
- unidade.

# 4. ROI

Pode:
- simular;
- usar dados do cliente;
- fazer sensibilidade;
- comparar cenários.

Não pode:
- prometer;
- selecionar só cenário otimista;
- omitir custo relevante.

# 5. Concorrência

Pode comparar capacidade documentada.

Não pode inventar defeito.

# 6. Privacidade

Coletar só o necessário.
Usar dentro da finalidade.
Respeitar acesso.
Não expor dados entre contas.

# 7. Mensageria

Respeitar:
- opt-out;
- canal;
- política;
- autorização;
- frequência;
- reputação.

# 8. Gravação de reunião

Seguir política/jurisdição e informar quando aplicável.

# 9. IA

Nunca dizer que ação aconteceu se ferramenta não confirmou.

# 10. Escalada

Questão jurídica/fiscal/segurança relevante vai para responsável adequado.

# 11. Incentivo

Meta não justifica violação.

# 12. Avaliação

Qualquer falha crítica deste módulo reprova certificação.
