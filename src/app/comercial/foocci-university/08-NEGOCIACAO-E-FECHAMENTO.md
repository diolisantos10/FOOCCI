# 08 — Negociação, Fechamento e Próximos Passos

## Princípio

Fechamento não é uma frase mágica. É consequência de processo bem conduzido.

# 1. Negociação por interesses

Separar:
- **posição:** “quero 30% de desconto”;
- **interesse:** “não consigo aprovar esse valor neste trimestre”.

Perguntar o motivo antes de ceder.

# 2. BATNA

Antes de negociar, saber:
- sua melhor alternativa sem acordo;
- alternativa do cliente;
- limite;
- concessões possíveis.

Vendedor sem BATNA negocia por medo.

# 3. Âncoras

Preço deve ser contextualizado pelo problema e valor antes de virar número isolado.

Não usar âncora falsa.

# 4. Concessões

Concessão deve ser:
- rara;
- explícita;
- condicional;
- registrada.

Exemplo:
“Se fecharmos no ciclo anual, consigo aplicar a condição prevista para esse ciclo.”

Não inventar condição fora da política.

# 5. Fechamento por confirmação

Perguntas:
- “Faz sentido seguir?”
- “O que falta para decidir?”
- “Quem precisa entrar?”
- “Se resolvermos X, você está confortável para contratar?”

# 6. Mutual Action Plan

Para vendas maiores, criar plano bilateral:

| Etapa | Dono | Data | Saída |
|---|---|---|---|
| Demo técnica | Foocci | dd/mm | requisitos validados |
| Revisão de integração | Cliente/Foocci | dd/mm | go/no-go |
| Comercial | Decisor | dd/mm | plano/ciclo |
| Cadastro | Cliente | dd/mm | dados completos |
| Implantação | Ambos | dd/mm | operação ativa |

# 7. Fechamento administrativo

Venda só fecha quando:
- plano definido;
- condição registrada;
- contrato/aceite concluído;
- pagamento ou processo de cobrança iniciado;
- handoff feito;
- próximo passo de implantação agendado.

“Falou que vai fechar” não é venda.

# 8. No-decision

O maior concorrente costuma ser não fazer nada.

Pergunta:
“Se vocês não mudarem nada nos próximos seis meses, qual é o custo?”

Não dramatizar. Quantificar.

# 9. Desconto

Preço vigente deve ser consultado na fonte oficial. O material de treinamento não autoriza desconto adicional.

# 10. Fechamento perdido

Registrar motivo real:
- sem fit;
- preço;
- prioridade;
- concorrente;
- requisito;
- timing;
- decisor;
- sem resposta.

“Sumiu” não é motivo suficiente.

# 11. Win/Loss

Todo negócio relevante gera aprendizado:
- por que ganhamos;
- por que perdemos;
- etapa;
- concorrente;
- critério;
- objeção;
- mudança para próxima vez.

# 12. Exercício

Negociação simulada:
- cliente pede 25% de desconto;
- diz que concorrente custa metade;
- precisa falar com sócio;
- quer fechar só se houver integração específica.

O aluno deve preservar valor, identificar interesses e sair com decisão/ação concreta.
