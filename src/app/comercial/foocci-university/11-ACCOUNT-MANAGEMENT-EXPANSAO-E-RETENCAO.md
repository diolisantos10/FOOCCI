# 11 — Gestão de Conta, Expansão e Retenção

## Princípio

Venda não termina no pagamento. Receita ruim é aquela que fecha sem fit e vira churn.

# 1. Handoff comercial → implantação/CS

Transferir:
- objetivo do cliente;
- dores;
- promessas feitas;
- escopo;
- decisores;
- riscos;
- integrações;
- prazo;
- critério de sucesso.

Nunca obrigar cliente a repetir toda história.

# 2. Success plan

Definir:
- resultado desejado;
- comportamento que precisa mudar;
- marcos;
- dados;
- responsáveis.

# 3. Adoção

Sinais:
- login;
- configuração;
- uso de canal;
- pedidos;
- CRM;
- equipe;
- campanhas.

Adoção parcial exige intervenção antes de virar churn.

# 4. Expansão

Upsell/cross-sell só quando:
- existe necessidade;
- cliente já percebe valor;
- capacidade adicional resolve problema real.

Não usar expansão como cobrança surpresa.

# 5. QBR/Business Review

Para contas relevantes:
- objetivos;
- uso;
- impacto;
- oportunidades;
- riscos;
- próximos 90 dias.

# 6. Churn risk

Sinais:
- queda de uso;
- mudança de sponsor;
- tickets repetidos;
- promessa não entregue;
- pagamento atrasado;
- ausência;
- concorrente em avaliação.

# 7. Renovação

Começa muito antes do vencimento.

Renovação é consequência de:
- valor percebido;
- adoção;
- relacionamento;
- prova.

# 8. Advocacy

Cliente satisfeito pode:
- indicar;
- dar depoimento;
- participar de case;
- servir de referência.

Solicitar no momento em que valor foi percebido, não aleatoriamente.

# 9. Expansão por unidade

Para redes:
- provar em uma unidade;
- documentar resultado/processo;
- validar diferenças;
- criar rollout.

# 10. Comercial + CS

Métrica compartilhada:
**receita de qualidade**.

Vendedor não pode ganhar ao transferir problema para CS.
