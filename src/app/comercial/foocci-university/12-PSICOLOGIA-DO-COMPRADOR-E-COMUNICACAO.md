# 12 — Psicologia do Comprador e Comunicação Comercial

## Regra ética

Conhecer psicologia serve para reduzir fricção e melhorar decisão — não para manipular vulnerabilidade.

# 1. Aversão à perda

Pessoas frequentemente sentem perda mais intensamente que ganho equivalente.

Uso ético:
quantificar custo do status quo com dados reais.

Não usar medo fabricado.

# 2. Status quo

Mudança tem custo percebido.

Vendedor deve reduzir:
- risco;
- complexidade;
- incerteza;
- esforço.

Por isso demonstração, implantação e prova importam.

# 3. Sobrecarga de escolha

Mostrar 30 funcionalidades dificulta decisão.

Curar a conversa em torno de 2–4 capacidades relevantes.

# 4. Prova social

Case é forte quando semelhante:
- segmento;
- porte;
- dor;
- contexto.

Nunca inventar cliente ou resultado.

# 5. Autoridade

Autoridade legítima vem de:
- domínio;
- clareza;
- dados;
- reconhecer limite.

Dizer “não sei, vou confirmar” pode aumentar confiança.

# 6. Reciprocidade

Entregar insight útil antes de pedir compromisso.

Não usar brinde como dívida psicológica.

# 7. Compromisso e consistência

Pequenos compromissos reais ajudam avanço:
- enviar dado;
- incluir decisor;
- agendar demo;
- testar.

Não criar armadilha.

# 8. Linguagem

Preferir:
- frases curtas;
- exemplos;
- números contextualizados;
- pergunta após explicação.

Evitar:
- jargão;
- superlativo;
- buzzword de IA;
- “revolucionário”.

# 9. Escuta ativa

Técnicas:
- paráfrase;
- resumo;
- silêncio;
- espelhamento moderado;
- pergunta de aprofundamento.

# 10. Comunicação executiva

Estrutura:
**conclusão → evidência → impacto → próximo passo.**

# 11. Comunicação com operador

Estrutura:
**como funciona → o que muda na rotina → exceções → suporte.**

# 12. Comunicação por perfil

Dono: retorno, risco, controle.

Gerente: operação, adoção, exceção.

Marketing: canal, base, campanha, mensuração.

Financeiro: custo, contrato, previsibilidade.

TI/PDV: integração, segurança, dependência.
